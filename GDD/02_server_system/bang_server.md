## Gợi Ý Thảo Luận

Băng trong tự nhiên: đóng băng, làm chậm, bảo tồn, kiểm soát.

Đã biết về Băng từ các thảo luận trước:
- Băng + Hoả = đối lập cực đoan → tension ngay từ đầu
- Băng + Thuỷ = combo kiểm soát mạnh
- Băng + Thổ + Kim → "Băng Tiêu Địa Sụt" (combo emergent)
